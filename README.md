# まるさんしVR Built With Basis
まるさんしVRは、Basis Frameworkを用いた日本コミュニティ想定のフレームワークです。

開発主導、nodokaha（Twitter: [@bm9kb2thaGE](https://twitter.com/bm9kb2thaGE), GitHub: [nodokaha](https://github.com/nodokaha)）

MarusansiVRはnodokahaが個人的に保守、点検しておりまるさんかくしかくコミュニティとしての公式クライアントではありません
(利用を規定するものではありません)

サーバーとクライアントのセットに関して、自由な利用を想定しており要望があればご提案頂けると嬉しいです

また、もしもサーバーを動かしてテストしてみてるよなどあれば、教えてもらえると開発の参考になりますので是非お気軽にご連絡ください
(報告の義務はありません)
